# MAGAZZINO NOVA

Release clean-room del Magazzino Teramo.

Questa tree contiene esclusivamente NOVA. Il runtime REMOTO non viene caricato. La release `mobile-login-cleanup` include landing centrata con `MAGAZZINO / TERAMO`, topbar nascosta prima dell'accesso e layout smartphone forzato sotto 700 px.

Il pacchetto viene ricomposto da segmenti immutabili e verificato con SHA-256 prima dell'avvio. La CI esegue la stessa verifica, controlla i contratti UI/mobile e un flusso logistico Entrata Merci.
